# Data Dictionary - Asir Infrastructure Projects Dataset

قاموس البيانات الخاص بمشروع بيانات البنية التحتية والمشاريع التنموية في منطقة عسير (2019–2025).

| اسم العمود           | نوع البيانات | الوصف                                                        | أمثلة                                            |
| :------------------- | :----------- | :----------------------------------------------------------- | :----------------------------------------------- |
| **اسم المشروع**      | Text         | الاسم الرسمي للمشروع التنموي أو الخدمي                       | مطار أبها الدولي                                 |
| **القطاع**           | Text         | القطاع الذي ينتمي إليه المشروع                               | النقل والخدمات اللوجستية، السياحة، الصحة         |
| **الموقع**           | Text         | النطاق الجغرافي التفصيلي أو المراكز التي يشملها المشروع      | الفرشة - الربوعة - ظهران الجنوب                  |
| **المدينة الرئيسية** | Text         | المدينة أو المحافظة الرئيسية المرتبطة بالمشروع في منطقة عسير | أبها، خميس مشيط، محايل عسير                      |
| **الجهة المشرفة**    | Text         | الوزارة أو الهيئة المسؤولة عن المتابعة والإشراف على المشروع  | أمانة منطقة عسير، وزارة النقل                    |
| **الجهة المنفذة**    | Text         | الجهة أو الشركة المسؤولة عن تنفيذ المشروع                    | شركة آردارا للتطوير العقاري، الهيئة العامة للطرق |
| **حالة المشروع**     | Text         | الوضع التنفيذي الحالي للمشروع                                | قيد التنفيذ، مكتمل                               |
| **وصف المشروع**      | Text         | ملخص لأهداف المشروع ومكوناته الأساسية                        | مشروع توسعة شاملة وتحسين جودة الحياة...          |
| **المصدر**           | Text         | المصدر الذي تم الاعتماد عليه لجمع معلومات المشروع            | وكالة الأنباء السعودية (واس)، صحيفة سبق          |
