# Asir Infrastructure Projects Dataset

## Overview

This project contains a structured dataset of development and infrastructure projects in the Asir Region, Saudi Arabia.

The data has been collected and organized in Excel to make project information easier to explore and analyze.

## Dataset

The dataset covers projects in the Asir Region during the period **2019–2025**.

The information is organized in an Excel file and can be used as a foundation for data analysis and visualization.

## Project Goal

The goal of this project is to collect and organize information about development and infrastructure projects in the Asir Region into a structured dataset that can be used for further analysis.
